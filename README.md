# 🚀 My Portfolio

Welcome to my personal portfolio repository! This project showcases my work, skills, and experience in web development, built with modern technologies for performance and scalability.

## 🛠 Tech Stack

- **[Astro](https://astro.build/)** - Fast and optimized static site generation
- **[React](https://react.dev/)** - Interactive components for a dynamic experience
- **[Tailwind CSS](https://tailwindcss.com/)** - Utility-first styling for rapid UI development

## ✨ Features

- ⚡ **Blazing Fast Performance** – Thanks to Astro's lightweight rendering
- 🎨 **Responsive UI** – Built with Tailwind CSS for a seamless experience on all devices
- ⚙ **Dynamic Components** – React-powered interactive sections
- 🔥 **Dark Mode Support** – User-friendly theme switching
- 📜 **SEO Optimized** – Meta tags and structured data for better discoverability
- 📂 **Modular Codebase** – Easy to maintain and expand
